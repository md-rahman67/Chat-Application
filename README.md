# Chat Application

A simple chat application built to practice backend development and database operations using Node.js.

## Features

- Store and retrieve chat messages from the database
- Display sender and receiver details
- Show message content and timestamp
- Perform basic CRUD operations on chat records

## Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
